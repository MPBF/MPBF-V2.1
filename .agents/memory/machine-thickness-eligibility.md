---
name: Original thickness machine eligibility
description: Machine thickness limits refer to the original product thickness, not the automatically calculated universal thickness.
---

حدود السماكة المدخلة للماكينات تخص `thickness` الأصلية، وليست
`universal_thickness`. تطابق أهلية تشغيل الفيلم والتخطيط مع السماكة الأصلية.

**Why:** صحّح المستخدم هذا المعنى صراحةً بعد رفض منتج سماكته الأصلية ضمن
حدود الماكينة بسبب مقارنة تلك الحدود بالسماكة العالمية الأكبر. الافتراض
السابق بأن حدود الماكينة تخص السماكة العالمية غير صحيح.

**How to apply:** حافظ على المعنى نفسه عند تسجيل الرولات وإضافة أوامر
الإنتاج إلى الطوابير وفحص قدرات الماكينات. لا تحوّل حدود الماكينات القائمة
أو تعيد كتابتها لتوافق السماكة العالمية.

تبقى السماكة العالمية محسوبة ومخزنة تلقائيًا للحسابات الداخلية التي تحتاجها؛
هذا التصحيح ليس إذنًا لتغيير معادلتها أو حساب وزن المنتج.

**Why:** أكد المستخدم الفصل بين عرض السماكة الأصلية، ومعنى حدود الماكينات،
والاحتفاظ بالسماكة العالمية محسوبة تلقائيًا.
