# استيراد وتصدير بيانات النظام

الأداة في **الإدارة ← إدارة بيانات القاعدة**، وتتاح فقط لصاحب صلاحية `admin` الفعلية. الكتالوج مختصر: أسماء الجداول، عدد الأعمدة، روابط الجداول وإتاحة العمليات، دون عرض أسماء الأعمدة أو أنواعها. تظهر تفاصيل الربط فقط في نموذج الاستيراد.

## النطاق والسياسة

- جميع جداول بيانات النظام، بما فيها العملاء ومنتجات العملاء والمستخدمون والأدوار، متاحة للاستيراد والتصدير.
- جداول الجلسات وأسرار الخدمات والمصادقة والسجلات الأمنية وبيانات الأداة الداخلية مستثناة. الأعمدة السرية والحقول الأمنية محمية حتى داخل جدول بيانات مسموح.
- الإضافة الجديدة تحتاج تأكيدًا. تحديث السجلات الموجودة يحتاج الموافقة على الخلايا المحددة بعد المعاينة. لا يوجد حذف تلقائي، وأي إخفاق يمنع تطبيق الدفعة كاملة.
- المفاتيح الفريدة للسجلات الموجودة لا تُغيّر. الجداول دون مفتاح فريد تدعم الإضافة فقط. يمكن ترك المفتاح الآلي فارغًا لإضافة سجل جديد.
- الأعمدة المولّدة لا تقبل كتابة مباشرة، وتُحسب حقول منتجات العملاء المشتقة بالخوارزمية المشتركة نفسها التي تستخدمها شاشة المنتج.

## ملفات CSV وExcel ومعرّفات الأرقام

المعرّفات الرقمية في ملف خارجي قد تخص قاعدة مختلفة. لا تُستخدم للمطابقة أو للربط إلا بعد تأكيد المدير أنها تشير إلى قاعدة البيانات الحالية. يبقى فحص وجود العلاقات والمفاتيح والتعارضات إلزاميًا؛ التأكيد ليس تجاوزًا لهذه الفحوص.

يمكن أيضًا استخدام حزمة JSON محلية صادرة من الأداة، مع التحقق من مصدرها وسلامتها ومطابقة مخططها. تُنفّذ الصفوف التابعة بعد الصفوف التي تعتمد عليها؛ تُرفض الدورات التي لا يمكن إدخالها بأمان. تُحفظ الحدود العليا لتسلسلات المفاتيح قبل الإضافة وبعدها داخل المعاملة لتجنب اصطدام الإضافات اللاحقة.

## المستخدمون والصلاحيات

لا تُستورد كلمات المرور أو بصماتها ولا تُصدّرها الأداة. تُرفض الملفات ذات أعمدة كلمات المرور قبل حفظها كسجل تحميل. عند تحديث مستخدم موجود تبقى كلمة مروره وإعدادات المصادقة المحمية كما هي.

عند إضافة مستخدم، يُنشأ له داخليًا رمز عشوائي غير معروض وتُحفظ بصمته الآمنة، ويُفرض تغيير كلمة المرور. يجب تعيين كلمة مرور قابلة للاستخدام من إدارة المستخدمين؛ الأداة لا توزّع كلمات مرور مشتركة أو افتراضية.

لا يمكن للاستيراد تعطيل المدير الذي ينفّذه أو سحب صلاحية `admin` الصريحة منه. إنشاء دور إداري أو ربط مستخدم بدور إداري أو تفعيل وصوله الإداري يحتاج تأكيدًا مستقلًا في المعاينة، إضافة إلى تأكيد الإدراج أو الموافقة على التحديث.

## الحماية

تُحفظ نسخة مراجعة قبل كتابة أي بيانات أعمال. تُرفض المعاينة القديمة عند تغير البيانات أو العلاقات أو المخطط. تُحفظ نتيجة التطبيق لمنع تكرار الدفعة عند إعادة محاولة طلب لم تُعرف نتيجته. إلغاء استيراد سابق لا يحذف السجلات الجديدة ولا يطغى على تعديلات أحدث.

هذه المعاينات ونسخ مراجعة الاستيراد ليست بديلًا عن أرشيف النظام المشفّر الكامل. استخدم أداة النسخ الاحتياطية لذلك.

لم يُنفّذ أي استيراد لبيانات أعمال فعلية أثناء التطوير؛ تستخدم اختبارات الحفظ قواعد PostgreSQL مؤقتة فقط.
