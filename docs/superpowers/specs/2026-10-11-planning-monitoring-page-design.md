# التخطيط والمراقبة

## التصميم المعتمد

إنشاء صفحة رئيسية باسم «التخطيط والمراقبة» في القائمة الرئيسية، تحتوي
على تبويبي إدارة الإنتاج ومراقبة الإنتاج الموجودين، دون تغيير وظائفهما
أو بياناتهما أو صلاحياتهما.

تبقى صفحة الإنتاج والتشغيل للوحات الفيلم والطباعة والقص وخلط الخام.
يبقى المستودع مستقلًا دون تغيير.

## التنقل والصلاحيات

- المسار الرئيسي الجديد `/planning`، والمراقبة `/planning/monitoring`.
- تحويل رابط المراقبة القديم إلى المسار الجديد.
- `/production` يفتح أول تبويب تشغيل مسموح للمستخدم.
- تتبع قائمة التخطيط والتبويبات صلاحيات المستخدم الفعلي، بما فيها تجربة الأدوار.
- لا يمنح النقل صلاحيات إدارة أو مراقبة للمشغلين.
- تبقى مراقبة الإنتاج للمدير بصلاحية `admin` فقط.
- تبقى صفحات الرولات والروابط الخاصة بالمستودع متاحة بصلاحياتها السابقة.

## التنفيذ والتحقق

إعادة استخدام مكونات الإدارة والمراقبة الحالية، مع فصل مجموعتي التنقل
والعناوين؛ لا تغيير على الخادم أو قاعدة البيانات أو النشر.

تحديث اختبارات التنقل الحالية وإضافة تغطية الصفحة الجديدة، بما فيها
المنع المباشر وتجربة الدور وروابط المراقبة القديمة والتنقل على أحجام
الهاتف واللوحي والحاسوب بالعربية والإنجليزية. فحص الأنواع والبناء
والصفحات باستخدام واجهات معزولة دون تغيير بيانات التطبيق الحقيقية.
