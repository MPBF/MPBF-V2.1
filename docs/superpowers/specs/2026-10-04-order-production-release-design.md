# تحويل طلب العميل إلى الإنتاج

تصميم وافق عليه المستخدم: زر «تحويل للإنتاج» في قائمة الطلبات وتفاصيلها.

- الصلاحيات: `manage_orders` أو `admin`؛ مدير الإنتاج وحده لا يكتسب صلاحية تعديل طلب العميل.
- يحول طلب الانتظار أو المعلق أو المتوقف إلى `for_production`، بعد تحقق الخادم من وجود أمر إنتاج قابل للتنفيذ. لا يعيد فتح الملغي أو المكتمل أو المسلّم أو المؤرشف.
- يغير حالة طلب العميل فقط ويحفظ الحالة السابقة. لا يغير المنتجات والكميات أو حالات أوامر الإنتاج، ولا يبدأ التنفيذ ولا ينشئ رولات أو دفعات.
- معاملة تقفل الطلب ثم بنوده بترتيب ثابت. يتحقق الخادم من الحالة المتوقعة لمنع الكتابة فوق تغيير أحدث. إعادة التحويل لطلب جاهز أو قيد الإنتاج لا تتراجع به ولا تكرر أثر التحويل.
- تحديث القائمة والتفاصيل بعد النجاح، وتعطيل الزر أثناء الحفظ، وإظهار أخطاء مفهومة. العربية والإنجليزية، والهاتف واللوحي والحاسوب.
- التحقق: الصلاحيات، الحالات المحظورة، تغير الحالة بالتزامن، غياب بنود قابلة للتنفيذ، وعدم تعديل البنود أو سجلات التنفيذ؛ فحص الأنواع والترجمة واختبارات الطلبات ومتصفح معزول.
