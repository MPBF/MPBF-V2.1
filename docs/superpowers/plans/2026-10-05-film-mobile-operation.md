# التنفيذ

1. توسيع بيانات المنتج المقروءة والمجمدة بالمقاس والماستر باتش، مع الحفاظ
   على القيم الموجودة والـ null المسجل وعدم تغيير السجلات القديمة.
2. فصل عرض مجموعات الفيلم عن ملخصات الإدارة والطباعة والقص؛ تجميع حسب
   order_id بفتح مجموعة واحدة، وبحث ومسودات مستقرة وإجراءات الهاتف.
3. اختبار اللون والمقاس والتجميد والحقول القديمة في PostgreSQL المعزول.
4. اختبار التجميع والبحث والأرقام العربية/الإنجليزية والمقاسات الصغيرة
   والصلاحيات وبدء العمل وفقد الاستجابة وإعادة المحاولة وحفظ مسودات أحدث.
5. فحص الأنواع، إعادة تشغيل واحدة، فحص السجلات والمظهر، دون نشر.
