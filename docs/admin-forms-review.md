# مراجعة نماذج الإدارة

## النطاق المعتمد

المستخدمون، الأدوار والصلاحيات، الأقسام، الماكينات، مكونات الصيانة،
التصنيفات، الأصناف، وألوان الماستر باتش.

- الحفاظ على جميع السجلات والرموز القديمة؛ لا تنظيف تلقائي ولا إعادة ترقيم.
- يولّد الخادم الرموز الجديدة تلقائيًا، وتكون غير قابلة للتعديل.
- معرّفات المستخدمين والأدوار ومكونات الصيانة أرقام تلقائية موجودة أصلًا.
- متابعة سلسلة `SEC` للأقسام، و`CAT` للتصنيفات، و`ITM` للأصناف،
  و`MAC` للماكينات، واستخدام `MB` للألوان الجديدة دون المساس برموز المورد القديمة.
- عدادات دائمة لتجنب إعادة استخدام الرموز المحذوفة؛ أقفال معاملات لمنع التكرار.
- إزالة حقل الترتيب وإدخال الكود المنفصل من النماذج، دون حذف قيمهما القديمة.
- مسميات مطابقة للحقول الفعلية، ووحدات واضحة لمواصفات الماكينات.
- قوائم للأدوار والأقسام والحالات والأنواع والارتباطات؛ تبقى الأسماء
  واسم الدخول والملاحظات والأرقام التسلسلية حقولًا حرة.
- إبقاء العلاقات القديمة غير المتاحة ظاهرة ومحفوظة عند عدم تغييرها،
  ورفض العلاقات الجديدة غير الصحيحة.
- حماية الصلاحيات، والتحقق من القيم وحدود المواصفات ومنع حلقات التصنيفات.
- لا تعديلات على قاعدة الإنتاج، ولا تغييرات خارج النماذج المطلوبة.

## التحقق

اختبارات للخادم وتوليد الرموز والتحقق من النماذج، وفحص أنواع وبناء،
وفحص تفاعلي ببيانات اصطناعية مع عزل طلبات API عند عروض الهاتف والتابلت والكمبيوتر.
